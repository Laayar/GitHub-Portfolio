# Développer des sites web statiques
[]()

## Description
[]()

A responsive website created as a first web development project at OFPPT. The site presents an establishment interface where visitors can discover training programs, register as new trainees, re-register as former trainees, access a login form, and contact the establishment.

## Live Demo
[]()

## Features
[]()

- Responsive Navigation: A Bootstrap navigation bar with links to the homepage, registration options, training programs, and contact page.
- Homepage Carousel: A carousel displaying the establishment's presentation slides.
- Training Programs: Card-based presentation of the available training streams.
- New Trainee Registration: A form for entering personal information, education level, selected training stream, and password.
- Former Trainee Re-registration: A form for entering trainee details and previous registration information.
- Login Form: A connection form for trainee identification and password entry.
- Contact Form: A form for sending a message, accompanied by a location map.
- Establishment Information: Contact details, address, email, phone number, and social media links displayed in the footer.
- Responsive Design: Layout components adapted to different screen sizes using Bootstrap.
